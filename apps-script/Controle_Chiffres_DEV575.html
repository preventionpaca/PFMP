Codes postaux sans 0 initial

Une colonne « Code postal » de type Nombre dans Grist transforme 06160 en 6160 : adresses fausses, géocodage impossible, entreprises mal rapprochées. L’analyse ne modifie rien ; la correction passe ces colonnes en Texte puis remet le 0.
