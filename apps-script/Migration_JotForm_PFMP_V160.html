DEV.330 — Résolution rapide + Monaco / NIS
Chaque bouton affiche son traitement dans la carte concernée. Vous pouvez corriger plusieurs dossiers sans attendre un rechargement complet ; cliquez ensuite sur « Actualiser les anomalies ». Pour Monaco, utilisez le NIS : aucun faux SIRET n’est créé.
DEV.328 — Résolution guidée et vérifiée
Chaque anomalie se valide individuellement. Une correction de période ne crée pas immédiatement une convention. Le bouton global d’import ne crée ensuite que les dossiers devenus sûrs.
DEV.327 — Résoudre les anomalies restantes
Corrigez ici périodes, anciens rattachements, conventions incomplètes et entreprises. Le CSV n’a plus besoin d’être modifié.







 

  DEV.325 — Anti-doublons de périodes
 


 

  Une ancienne convention reste reconnue même si l’ID de sa période officielle a changé. En cas d’ambiguïté, l’import est bloqué au lieu de créer un doublon.
 


 

  

  
 


 








 

  DEV.324 — Récupération rapide SIREN / SIRET
 


 

  Traitement par lots : 8 recherches API parallèles puis une seule mise à jour Grist groupée.
 


 

  

  
 


 








 

  DEV.323 — Récupération automatique des entreprises
 


 

  Traite les SIRET à vérifier, les SIREN à 9 chiffres et tente de retrouver les SIRET absents/invalides par le nom et l’adresse de l’entreprise. Seuls les rapprochements à forte confiance sont écrits dans le tampon.
 


 

  

  
 


 








 

  DEV.322 — Import différentiel JotForm
 

 

  Vous pouvez charger un export complet : les conventions déjà présentes sont reconnues et sorties automatiquement de l’import. Seuls les nouveaux dossiers sûrs seront créés.
