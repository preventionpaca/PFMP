Administration PFMP › Soumissions à traiter

Procédure

  1. Rien à faire pour un dépôt au SIRET vérifié : il apparaît déjà « Convention enregistrée » dans le suivi. Il n’est pas listé ici (filtre « Déjà dans le suivi » pour le consulter).
  2. Identifier l’entreprise : si elle est déjà connue, cliquez sa proposition (« Déjà connue dans la base »). Sinon : France → corrigez le SIRET puis « Vérifier le SIRET » ; Monaco → saisissez le NIS (4 chiffres, 1 lettre, 5 chiffres, ex. 7112B19343, à vérifier sur monentreprise.gouv.mc), le nom et l’adresse, puis « Enregistrer l’entreprise de Monaco ». Une fois identifiée, la soumission passe dans le suivi : c’est fini.
  3. Monaco sans NIS connu : « Chercher au registre de Monaco (RCI) » reprend nom, adresse et NIS de la fiche publique (le NIS du RCI est indicatif : en cas de doute, celui de monentreprise.gouv.mc fait foi). Introuvable : « Pas de NIS : numéro interne » (EUC-MC-0001…).
  4. Doublon ou abandon : « Classer sans suite ». Rien n’est effacé.

Courriel « Problème résolu : ta convention de stage est enregistrée — n° … », une seule fois par élève.

Dépôt ouvert depuis le courriel de l’équipe.
