Générer des conventions PFMP

Par défaut, la convention reprend la classe actuelle de l’élève. La classe portée par la convention peut être modifiée à la marge, notamment pour préparer une convention de l’année supérieure.

Les périodes sont maintenant pré-filtrées : seules les lignes dont l’intitulé commence par PFMP sont proposées pour CAP/Bac Pro ; pour les BTS, seules les lignes commençant par Stage BTS sont proposées. Le niveau est ensuite privilégié à partir de la classe.
