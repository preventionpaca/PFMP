Accès temporaires des professeurs principaux

Un code ouvre uniquement une classe et une période. Il expire automatiquement le dernier jour de la PFMP.

Accueil PFMP›Administration PFMP›Accès professeurs principaux

Campagne de codes par niveau

Choisissez la famille, le niveau et la période : le lot rassemble toutes les classes de ce niveau qui ont cette période (même libellé, mêmes dates). Chaque professeur principal reçoit son code par un courriel individuel. Choisir une classe limite le lot à cette classe ; « Tous les niveaux » reprend toute la famille.

Codes direction (permanents)

Recours de dernier ressort pour le proviseur et les adjoints : un code personnel, sans date de fin, qui permet d’affecter les professeurs de toutes les classes et de toutes les périodes depuis Suivi PFMP (« Accès professeur principal »). Il reste valable jusqu’à sa révocation.
