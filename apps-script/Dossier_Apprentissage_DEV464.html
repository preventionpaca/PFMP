3. Choisir le modèle et générer

Le fichier Word reste votre base modifiable. Après chaque évolution, exportez-le en PDF puis chargez ce PDF ici : aucun passage par Google Docs n’est nécessaire.

Gérer les modèles PDF

La fusion se fait directement dans le PDF chargé. Les balises doivent rester du texte continu, par exemple {{ELEVE_NOM}}, sans saut de ligne à l’intérieur. La date d’édition est ajoutée au pied de toutes les pages. Le registre n’est alimenté qu’après clic sur « Confirmer la distribution » ; une distribution enregistrée par erreur peut ensuite être annulée sans supprimer l’historique.
