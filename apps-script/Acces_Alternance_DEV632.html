Je suis apprenti(e)

Tapez le code personnel imprimé sous votre QR code (par exemple L1F-3A9C2B7E) : vous arrivez dans votre livret et retrouvez tout ce que vous avez déjà saisi.

Je suis professeur

Indiquez votre adresse professionnelle : si elle figure dans la liste des professeurs du lycée, le lien de votre espace référent (vos apprentis, leurs bilans de visite et leurs livrets) vous y est envoyé.

Tuteurs en entreprise : vous n’avez rien à saisir ici. Vous validez les fiches de votre apprenti en scannant le QR code qu’il vous présente, ou avec le lien reçu par courriel.
