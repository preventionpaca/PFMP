Import des élèves depuis Pronote

IMPORT RÉEL CONTRÔLÉ — les correspondances de classes et, après confirmation, les élèves sont écrits dans Grist. Aucune suppression automatique n’est effectuée.

← Retour au centre d’administration PFMP

En mode automatique, la source est déterminée dès l’analyse. Dès qu’elle est détectée, le menu bascule visuellement sur LP ou LGT et cette valeur est utilisée pour les mémorisations et l’import.

Le tableau doit contenir au minimum : nom, prénom, classe, date d’entrée et date de sortie. Le professeur principal est récupéré automatiquement si la colonne correspondante est présente.

Préparation des classes Pronote

Pour chaque classe, rattachez-la à une classe Grist ou mettez-la de côté. Vous pouvez mémoriser ces choix pour l’année et la source détectée/sélectionnée.
