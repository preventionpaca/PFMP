# Intégration PFMP et alternance

Après audit, les périodes d'accueil devraient référencer l'établissement (`EUC_ENTREPRISES`) et, si utile, un tuteur (`EUC_CONTACTS_ENTREPRISES`). Les formations, capacités, périodes possibles, appréciations et historique d'accueil peuvent être portés par des tables de liaison uniquement si les besoins réels justifient cette granularité. Aucune table calendrier ne doit absorber les fiches entreprises.
